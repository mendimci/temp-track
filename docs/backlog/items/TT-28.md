## Goal
Add Dockerfiles (API; web via nginx with an entrypoint that writes `/config.json` from env), `docker-compose.yml` (PostgreSQL 17, api, web; DB not exposed beyond the compose network except for local dev), `.env.example`, and a Playwright + `@axe-core/playwright` harness with a CI `e2e-smoke` job that runs against `docker compose up`. This is the local "dev environment" for the PoC (no hosted deploy).

## Areas likely touched
`src/api/Dockerfile`, `src/web/Dockerfile`, `src/web/nginx.conf`, `docker-compose.yml`, `.env.example`, `tests/e2e/`, `.github/workflows/ci.yml`, README

## Acceptance checks
- `docker compose up` starts db, api and web; `/health` is green; SPA loads at http://localhost:5173 (or configured port)
- `.env.example` holds dummy values only; `.env` is git-ignored
- Playwright harness has a shared axe helper (fails on serious/critical)
- Smoke test: `app shell loads and passes axe` in CI `e2e-smoke` job
