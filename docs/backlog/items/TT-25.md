## Goal
Create the React 19 + TypeScript (strict) Vite app with React Router, TanStack Query, ESLint + Prettier, runtime `/config.json` loading, an accessible app shell (header, nav, main landmark, skip link), CSS variables for colour/focus, and a typed API client generated from `docs/api/openapi.yaml` (openapi-typescript + openapi-fetch) that sends `X-Correlation-ID`.

## Areas likely touched
`src/web/` (package.json, vite config, eslint/prettier config, src/main.tsx, src/api/, src/components/layout, public/config.json), root README dev section

## Acceptance checks
- `npm run lint`, `npm run format:check`, `npm run typecheck`, `npm run build` pass
- App reads `apiUrl` and `authMode` from `/config.json` at start
- `npm run gen:api` regenerates types from `docs/api/openapi.yaml`
- Shell has a skip link, `<header>`, `<nav>`, `<main>`, visible focus ring; contrast via CSS variables >= 4.5:1
- Smoke test: Vitest render test that the shell mounts

## Dependencies
- None
