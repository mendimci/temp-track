## Goal
Create the .NET 10 solution and a runnable ASP.NET Core minimal-API project with `/health` (incl. DB check), JSON console logging, correlation-ID middleware, ProblemDetails, EF Core DbContext on PostgreSQL with migrate-on-startup, build-time OpenAPI generation, and the test project.

## Areas likely touched
`TempTrack.slnx`, `global.json`, `Directory.Build.props`, `.editorconfig`, `src/api/` (Program.cs, Infrastructure/Http, Infrastructure/Persistence), `tests/api/TempTrack.Api.Tests/`, `docs/api/openapi.yaml`

## Acceptance checks
- `dotnet build` and `dotnet format --verify-no-changes` pass
- `GET /health` returns 200 with DB status when PostgreSQL is reachable
- Every response carries `X-Correlation-ID` (echoed or generated); logs are JSON on stdout
- Unhandled exception returns ProblemDetails 500 with correlation id, no stack trace outside Development
- OpenAPI document is generated by the build into `docs/api/openapi.yaml`
- NuGet lock files enabled (`RestorePackagesWithLockFile`) so the SBOM sees packages
- Smoke test: `Health_returns_ok` (WebApplicationFactory + Testcontainers PostgreSQL)
